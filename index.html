01 / Sobre o projeto

Aprender pode ser mais simples.

O Aprende+ é uma plataforma educacional digital voltada a estudantes do ensino fundamental II e médio da rede pública. A proposta transforma temas do cotidiano, como alimentação escolar, uso de água e sustentabilidade, em experiências de aprendizagem curtas, visuais e interativas.

Com uma abordagem mobile-first, a plataforma combina conteúdos educativos, atividades de verificação, acompanhamento de progresso e o apoio complementar de um Tutor IA, aproximando o conhecimento da realidade dos estudantes.

Foco

02 / O desafio

Tornar o aprendizado mais próximo da realidade.

Como transformar informações educacionais em experiências acessíveis, envolventes e fáceis de compreender? O desafio do Aprende+ foi aproximar os conteúdos escolares de situações reais, facilitar a interpretação de informações visuais e manter o estudante engajado sem gerar sobrecarga durante a aprendizagem.

  1. 01

    Conexão com o cotidiano

    Relacionar conteúdos escolares a situações reais, tornando o aprendizado mais significativo.

  2. 02

    Clareza visual

    Facilitar a compreensão de gráficos, comparações e informações visuais sem perder a profundidade do conteúdo.

  3. 03

    Engajamento

    Manter o interesse dos estudantes com atividades curtas, progresso visível e uma experiência sem sobrecarga.

03 / Público-alvo

Uma experiência pensada para diferentes estudantes.

O Aprende+ foi desenvolvido pensando em estudantes do ensino fundamental II e médio da rede pública, considerando diferentes realidades socioculturais, níveis de familiaridade com a tecnologia e o acesso predominante por smartphones.

Para atender a esse público, a experiência prioriza linguagem simples, navegação previsível, conteúdos organizados em etapas curtas e interfaces intuitivas, que não exigem experiência prévia com plataformas educacionais complexas.

  • Ensino fundamental II e médio
  • Diferentes níveis de familiaridade digital
  • Acesso prioritário por smartphones

A experiência do Aprende+ foi estruturada para acompanhar o estudante desde o primeiro acesso até a consolidação do aprendizado. Cada etapa foi planejada para oferecer clareza, personalização e continuidade.

01 / Sobre o projeto

Simplificar também é transformar.

O Regulariza BR é uma proposta de aplicativo mobile voltada à regularização de pendências veiculares. A solução foi desenvolvida para facilitar a compreensão de débitos, orientar motoristas sobre as etapas necessárias e oferecer uma jornada mais clara, centralizada e acessível.

O projeto explora como o UX/UI Design pode simplificar processos públicos complexos, transformando informações burocráticas em uma experiência digital organizada, intuitiva e orientada às necessidades do cidadão.

Público
Motoristas com pendências veiculares
Abordagem
Mobile-first
Foco
Clareza, orientação e regularização

Projeto conceitual de UX/UI. Não é um serviço oficial do governo; usa o Padrão Digital GOV.BR apenas como referência.

02 / O desafio

Quando a burocracia vira uma barreira.

Receber uma notificação de irregularidade veicular pode gerar dúvidas sobre o motivo da pendência, os valores envolvidos, os prazos e os procedimentos necessários para resolver a situação. O desafio foi organizar essas informações em uma jornada simples e compreensível, reduzindo a dificuldade de encontrar respostas e entender o próximo passo.

  1. 01

    Clareza das informações

    Explicar pendências, débitos e procedimentos com linguagem objetiva e acessível.

  2. 02

    Orientação durante o processo

    Permitir que o motorista compreenda o que precisa fazer, quais opções estão disponíveis e como acompanhar a regularização.

  3. 03

    Redução da complexidade

    Organizar etapas e informações burocráticas em um fluxo digital intuitivo, evitando dúvidas e sobrecarga.

03 / Público-alvo

Uma experiência centrada no cidadão.

O projeto foi pensado para motoristas que recebem notificações relacionadas a irregularidades veiculares e precisam compreender sua situação e os caminhos disponíveis para regularização.

O aplicativo prioriza a apresentação de informações essenciais, uma navegação previsível e orientações claras para que diferentes perfis de usuários consigam compreender o processo.

  • Motoristas notificados sobre pendências
  • Necessidade de informações objetivas
  • Acesso simplificado aos procedimentos
04 / Jornada do usuário

A jornada acompanha o motorista desde o alerta recebido até o acompanhamento da regularização, com caminhos alternativos documentados no protótipo.

08 / Acessibilidade e experiência

Informação pública precisa ser compreensível.

Em uma experiência que envolve informações e procedimentos de regularização veicular, clareza e previsibilidade são fundamentais. O projeto prioriza linguagem objetiva, organização visual e orientações que ajudem o usuário a compreender sua situação e as ações disponíveis.

01Linguagem clara

Orientações diretas sobre o que aconteceu e o que fazer em seguida.

02Hierarquia

Informações importantes, como débitos e total, em destaque.

03Navegação consistente

Mesma estrutura de cabeçalho, retorno e navegação em todas as telas.

04Feedback de estados

Avisos, erros e sucesso com ícone, fundo e texto, não só cor.

Área de toque mínima de 44 × 44px e contraste mínimo de texto de 4,5:1 foram definidos como diretrizes no Design System. Não foram realizados testes formais de acessibilidade.

01 / Sobre o projeto

Tecnologia para uma gestão mais eficiente.

React NativeTypeScriptNode.jsExpressPrismaPostgreSQL

O CINOVA é uma plataforma digital desenvolvida para substituir métodos manuais e informais de gestão de manutenção predial. A solução centraliza o gerenciamento de ordens de serviço, facilitando a organização das solicitações e a comunicação entre moradores, técnicos e síndicos.

Com uma aplicação mobile integrada a uma API e banco de dados, o projeto busca oferecer maior transparência, controle e rastreabilidade das atividades de manutenção, permitindo que diferentes usuários acompanhem informações e processos diretamente pelo smartphone.

No código, o projeto aparece com o nome de trabalho SGMP; CINOVA é a identidade visual do app.

02 / O problema

Quando a manutenção depende de processos informais.

A gestão de manutenção predial pode envolver solicitações dispersas, comunicação fragmentada e dificuldade para acompanhar o andamento dos serviços. Sem uma estrutura centralizada, torna-se mais difícil organizar informações, consultar históricos e manter a transparência entre os envolvidos.

  1. 01

    Informações descentralizadas

    Organizar solicitações e registros de manutenção em um único ambiente digital.

  2. 02

    Comunicação entre diferentes usuários

    Facilitar a troca de informações entre moradores, técnicos e administradores.

  3. 03

    Controle e rastreabilidade

    Permitir que as ordens de serviço sejam registradas, consultadas e acompanhadas de maneira estruturada.

03 / Usuários e necessidades

Diferentes usuários, uma gestão conectada.

CINOVAAPI + banco de dados

Os três perfis existem no código como o enum Papel (MORADOR, FUNCIONARIO, SINDICO). Após o login, a API retorna o papel do usuário e o app abre a área correspondente.

Responsável pelas interfaces, navegação e interação dos usuários com as funcionalidades de manutenção predial.

  • src/screens telas por papel: morador, síndico e técnico
  • src/services chamadas à API com Axios
  • src/contexto contexto de autenticação
  • src/hooks hooks como useCriacaoOS
  • Testes com Jest em __tests__
Back-end

API REST em camadas

Responsável pela disponibilização das funcionalidades da API e pelo processamento das requisições do aplicativo.

  • routes definem os endpoints
  • controllers tratam requisição e resposta
  • repositories concentram o acesso aos dados
  • 6 grupos de rotas: auth, usuários, moradores, funcionários, síndicos e ordens de serviço
Prisma ORM

Modelo e migrações

Utilizado na interação da aplicação com os dados persistidos no banco.

  • Esquema em prisma/schema.prisma
  • Migrações versionadas em prisma/migrations
  • Dados iniciais com prisma/seed.ts
PostgreSQL

Dados relacionais

Banco de dados relacional utilizado para armazenar as informações do sistema.

  • Imagem postgres:16 via docker-compose
  • 5 tabelas: Usuario, Morador, Funcionario, Sindico e OrdemServico
  • Rota GET /db-test verifica a conexão

Persistência de dados

Trecho real de schema.prisma: a ordem liga morador, síndico e funcionário executor.

model OrdemServico {
  id            Int       @id @default(autoincrement())
  descricao     String
  dataAbertura  DateTime  @default(now())
  dataConclusao DateTime?
  status        StatusOrdemServico @default(PENDENTE_APROVACAO)

  cpf_morador     String
  morador         Morador      @relation(...)
  cpf_sindico     String?
  sindico         Sindico?     @relation(...)
  cpf_funcionario String?
  executor        Funcionario? @relation(...)
}

Integração app ↔ API

O app cria uma ordem com Axios; a API repassa ao repositório, que grava com o Prisma. Código real dos dois repositórios.

// sgmp-mobile · src/services/ordemServico.ts
export const criarOrdemServico = async (payload: {
  descricao: string; cpf_morador: string;
}) => {
  const { data } = await api.post("/ordens-servico", payload);
  return data;
};
↓ POST /ordens-servico 
// sgmp-api · src/controllers/ordemServicoController.ts
async create(req, res) {
  const ordemServico = await ordemServicoRepository.create(req.body);

10 / Resultados e aprendizados

Muito além de um aplicativo.

O CINOVA reúne desenvolvimento mobile, construção de API e persistência de dados em uma proposta integrada de gestão predial. O projeto representa uma experiência prática de desenvolvimento colaborativo, organização técnica e construção de soluções voltadas a necessidades reais.

Seu desenvolvimento envolve decisões relacionadas à estruturação de funcionalidades, comunicação entre camadas e organização de informações, demonstrando como diferentes tecnologias podem trabalhar juntas para formar uma aplicação completa.

Critérios de sucesso planejados · não medidos
  • Entrega dentro do prazo e orçamento
  • Satisfação nos testes acima de 90%
  • Redução de 50% no tempo de registro de ordens de serviço
